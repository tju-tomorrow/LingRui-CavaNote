## 2. 播放器

| 能力 | 规格 |
|---|---|
| 播放 / 暂停 | `playing: boolean`，rAF 驱动 `t += dt * speed` |
| seek | 拖动进度条 → `t = target`，立即 `sampleAt` 重绘（无副作用） |
| 速度档 | `0.5 / 1.0 / 1.5 / 2.0` |
| 快进 | 跳到**下一个分镜** `chapter.start` 的 `t` |
| 重播 | `t = 0` 并播放 |
| 时长 | `SceneScript.duration`，显示 `mm:ss / mm:ss` |

**分帧原则（ADR-0005）**：Excalidraw 与 PixiJS 各自渲染；动画期间**禁止** React 全树重渲染。
播放器状态放 ref/外部 store，只有 UI 控件（按钮/进度条）订阅。

---

## 3. seek 四联动（核心体验）

拖动/播放到 `t` 时，四件事**同一帧**对齐：

1. **画布**：`sampleAt(t)` 决定节点 appear、连线 draw、flow 位置、聚焦态。
2. **文档**：滚到当前 `focus` 节点的 `blockId`（平滑滚动，不抢焦点）。
3. **节点详情卡**：切到当前 `focus` 节点的卡（有则淡入，无则隐藏）。
4. **进度高亮**：时间轴对应的分镜缩略图 + 笔记进度项高亮。

> 由单一 `t` 派生，避免四处各自维护状态而漂移。

---

## 4. 分镜（Chapter / shot）

- 来源：`SceneScript` 的事件簇 → 按 `chapter.start` 切分；**AI 按讲解章节自动切分**
  （P3 由模型产出，P2 用写死 demo）。
- 展示：底部缩略图条，每格 = 章节首帧缩略图 + 标题 + 起始时间（对齐 `主界面.png`）。
- 交互：点击 → seek 到该章 `startT`（触发 §3 四联动）。
- 可人工重命名 / 合并 / 排序（写回 `chapters` root，见 `PRD/知识模型.md` §2.2）。

**缩略图生成**：在 `t = startT` 对画布离屏截图，缓存；内容变化时失效重建。

---

## 5. 笔记进度

- 数据：`NodeProgress`，per-user（见 `PRD/知识模型.md` §2.5）。
- 推进：时间轴 `focus` 到某节点 → 自动置 `learning`；全部动作播完 → `done`。
- 手动：可勾选 `done` / 取消。
- 展示：右侧「笔记进度」清单，当前节点高亮。

> VRM 只是其中一种形态（像素优先）。见 [`PRD/宠物.md`](./宠物.md)。
> `mascot.*` 动作泛化为 `pet.*`（保留别名）。

- 现状：`createMascotController` 抛未实现；无 `.vrm` 资产。
- 规格：`three + @pixiv/three-vrm`，独立 canvas 合成到画布覆盖层。
