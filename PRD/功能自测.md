## 三、已修 Bug（本轮）

| Bug | 根因 | 修复 |
|---|---|---|
| **删除/编辑笔记后白屏卡死**（重复 key 刷屏） | `rooth order` 数组因并发 upsert 出现**重复 id** → 节点列表渲染出重复 React key → 反复报错 + 渲染风暴 | `useKnowledgeNodes.snapshot()` 读取侧去重 |
| **双击节点/画布 → 白屏卡死** | 双击生成的空 text 元素被落成 `type:"text"` 但无 `text` 字段的 Annotation；派生回场景时 `convertToExcalidrawElements` 对 `undefined` 调 `normalizeEOL` → 抛错打崩 `<CanvasStage>` | ① text 注释的 `text` 兜底成 `""`；② 空文字元素不落盘；③ 编辑中不 `updateScene`；④ 加回归测试 |
| 画布被压到**最小缩放 0.1**（节点缩成一团） | 首屏 `scrollToContent(undefined)` 在容器尺寸未就绪时执行 | 显式传元素 + `ResizeObserver` 补救一次 |
| **桌面窗口拖不动** | `titleBarStyle: hiddenInset` 无原生标题栏，缺可拖拽区域 | 顶栏加 drag 区，按钮/输入框 no-drag |
| **桌面端双击启动用不了 AI** | Finder 启动拿不到 shell 环境变量 | 主进程按优先级读 `env → ~/.config/lingrui/config.json → opencode auth.json` |
| 暗色下 Excalidraw 工具栏死白 | 未把主题传给 Excalidraw | `CanvasStage` 跟随 `<html data-theme>` |
| 暗色下当前笔记 / 项目卡片 / 筛选 chip 白块 | 硬编码浅色底 | 补暗色覆盖 |
| unicode 图标（▤ ◈ ▣ ◉ ⚙ …）粗细不一 | — | 换成统一 SVG 线性图标 |
| 文档标题乱换行 | BlockNote 默认 `padding: 0 54px` 挤窄正文 | 收窄内边距 |
| 首屏画布空白像坏了 | 种子异步 | 「正在加载知识画布…」提示 |
