## 0. 一句话

一个 **AI 与你共编** 的基建知识画布：AI 用工具生成初版 → 你自由拖动 / 改文字 / 加注释 →
你再提需求时，系统把 **画布截图 + 底层结构化数据** 一起喂给 AI → AI 基于「你改过的现状」
增量修改。文档是它的落盘形态，时间轴是它的演出形态。

## 1. 核心闭环（已定 · 产品的立身之本）

```
用户提需求
   │  (1) 生成
   ▼
AI 调用 Canvas 工具生成初版 ──► nodes / relations / layout / annotations
   │
   │  (2) 人工精修
   ▼
用户：拖动节点 · 改标题/摘要 · 手绘 · 便签 · 连线 · 删除
   │
   │  (3) 回灌上下文（原子快照）
   ▼
Context Packer 抓取 ──┬── ① 画布截图（整幅、超采样）
                      └── ② CanvasSnapshot（nodes + relations + layout
                                            + annotations + provenance + focus）
   │  (4) 增量修改
   ▼
AI 基于「用户改过的现状」产出 patch ──► 应用（可整轮撤销）──► 回到 (2)
```

### 不变量（写死，不得违背）

1. **人的编辑是权威的**：AI 每轮看到的是最新现状，不得把用户改动当噪声重置。
2. **增量而非重建**：AI 的修改必须是 patch，不得整体重建画布（否则抹掉用户内容）。
   → 取代 [ADR-0009](../docs/adr/0009-canvas-and-runtime-sync.md) 的「整体重建」，见
   [ADR-0011](../docs/adr/0011-ai-cocanvas-incremental-editing.md)。
3. **原子快照**：截图与底层数据必须同一版本、同一时刻冻结，否则两者对不上。
4. **稳定 id**：所有元素都有稳定 id，AI 只能通过 id 精确增删改，禁止「照着重画一个」。
5. **来源标记**：每个元素带 `provenance.origin = ai | human`（+ `dirty`），AI 改前可见。

### 为什么截图和数据要一起给

| 只给数据 | 只给截图 |
|---|---|
| 看不出「用户圈了哪块 / 便签写了啥 / 相对位置是否拥挤」等视觉语义 | 认不出元素 id，改不精确、无法引用 |

两者互补：**截图给视觉意图，结构化数据给可寻址 id**。

## 3. 数据模型缺口

主界面要落地，`@lingrui/knowledge` 的 `KnowledgeNode` 需要扩字段（全部进同一个 Y.Doc）：

| 字段 | 用途 | 对应图中元素 |
|---|---|---|
| `body` | 富文本/markdown 正文 | 节点详情卡「核心作用」 |
| `faq: {q, a?}[]` | 相关问题 | 详情卡「相关知识」 |
| `meta.tech: string[]` | 技术栈 chips | 详情卡「常见实现」 |
| `meta.icon` | 节点图标 | 画布节点 |
| `tags: string[]` | 标签 | 标签页 / 搜索 |
| `chapter` / `shot` | 分镜归属 | 缩略图 |
| `progress` | 学习进度 | 笔记进度 |
| `provenance: {origin, dirty?}` | 来源标记 | §1 不变量 5 |

另需新增 **Annotation 实体**（手绘/便签/注释）：`{ id, type, geometry, text?, provenance }`，
与节点、关系并列进 `CanvasSnapshot`。详见 ADR-0011。

## 5. 交互规格（已定 · v1）

### 5.1 AI 修改落地：三级保险（三者都要）

| 操作类型 | 落地方式 |
|---|---|
| **新增类**（新增节点/连线/便签/样式） | **直接应用**，不打断 |
| **破坏类**（改/删用户 `origin:human` 的元素） | 进**待确认补丁**，画布上以 ghost 高亮预览；用户逐条或「全部接受」 |
| **任意一轮** | 合并为**一个 undo 批次**，`⌘Z` 一次撤销整轮 |
| **收尾** | 回复附「本次改动清单」，可点击定位到对应元素 |

### 5.2 回灌上下文

- 截图：**整幅画布**（fit-to-content），2x 超采样，白底。
- 排除：吉祥物、临时选中框、开发网格；包含：节点、连线、便签、用户手绘。
- 附 viewport transform + 每元素 bbox（像素 ↔ id 对齐）。
- 与 `CanvasSnapshot` **同版本冻结**。

### 5.3 AI 写文档（不重复）

- AI 生成/更新节点时，同步维护正文块并双绑 `blockId`。
- **幂等**：以 `nodeId` 为键 upsert，存在则更新，不追加；同标题/同内容不重复写。
- 画布改动 → 文档 upsert，**单一真相**，绝不再存一份。

### 5.4 导出 / 保存 / 分享 / 演示

- **导出**：动态视频（Revideo → MP4/WebM）或文档正文（Markdown / PDF）。
  不做面向用户的 PNG / 场景 JSON 导出。
- **保存**：自动存已开；按钮 = 手动打**命名版本快照**；有脏标记。
- **分享**：生成**只读链接**。
- **▷ 演示**：全屏、隐藏编辑 UI、自动播放 SceneScript，`Esc` 退出。

### 5.5 左侧导航

- **笔记**：文档树。
- **知识库**：跨笔记的**全局 KnowledgeNode 图谱/索引**，按 kind 过滤、可搜索、可跳转。
- **项目**：笔记集合/文件夹。
- **标签**：横切标签，可打在**笔记和节点**上，有独立索引页。
- **设置**：主题、协同、AI 模型、导出偏好。

### 5.6 搜索（⌘K）

命令面板：搜笔记标题 / 正文 / 节点 / 标签，结果按类型分组；
动作 = 跳笔记 / 画布聚焦节点 / 就地建节点。

### 5.7 时间轴 + 分镜 + 进度

- 播放 **SceneScript**；P2 无 AI 时先播**写死的 demo script**。
- 速度档 0.5 / 1.0 / 1.5 / 2.0；快进 = 跳下一个 shot；重播 = 归零播放。
- **seek 四联动**：画布动画 + 文档滚到对应 `blockId` + 节点卡切换 + 进度高亮。
- **分镜缩略图**：SceneScript 的 shot 列表，AI 按讲解章节自动切分，可人工重命名/合并；
  点击 = seek + 文档联动。
- **笔记进度**：**时间轴自动推进 + 可手动勾选**，存 Y.Doc；协同开启时同步。

### 5.8 明确不做（本期）

- 画布上的**步骤号 ①②③**（保留带标签箭头）。

### 5.9 便签 / 手绘

一等公民 `Annotation`（有 id、进 Y.Doc、可协同、AI 可引用）。见 ADR-0011。

## 6. 验收标准（主界面）

- [ ] 打开即见左侧图标导航 + 可折叠笔记树 + 主标题区，布局对齐 `主界面.png`。
- [ ] 画布节点带语义图标，颜色/手绘风与图一致。
- [ ] 点击节点弹出详情卡：核心作用 / 常见实现 chips / 相关知识链接。
- [ ] 用户可拖动、双击改文字、手绘、加便签；这些改动刷新后仍在。
- [ ] 用户改动后再次提问，AI 能看到**整幅截图 + CanvasSnapshot**并只做**增量修改**，
      不抹掉用户内容。
- [ ] AI 的新增类改动直接应用；破坏类改动以 ghost 预览待确认。
- [ ] AI 一轮修改可作为**一个**操作整体撤销（`⌘Z`）。
- [ ] AI 写文档为**幂等 upsert**，不产生重复块。
- [ ] 时间轴可播放/暂停/seek，速度档可切；分镜缩略图可点击定位。
- [ ] seek 时画布 / 文档 / 节点卡 / 进度四者联动。
- [ ] 笔记进度随播放自动推进，且可手动勾选。
- [ ] 导出产出动态视频或文档正文。
