## 0. UI 全面库化（已完成）

手写的蓝紫配色与自画图标全部下线，改用公开库：

| 类别 | 用库 | 落点 |
|---|---|---|
| 组件原语 | **shadcn/ui + Radix**（`radix-ui`） | `components/ui/{button,dialog,dropdown-menu,context-menu,input,badge,tooltip}.tsx` |
| 样式 | **Tailwind CSS v4** + `tw-animate-css` | 全部新组件用工具类；`lib/utils.ts` 的 `cn()` |
| 图标 | **lucide-react**（6356 个） | `shell/icons.tsx` 改为 lucide 转发；TopBar / 笔记树直接用 lucide |
| 主题 | **shadcn zinc 中性色** | 删掉自写的蓝紫 `#5b5bd6`，`--accent` → 近黑 |
| 块编辑器 | **@blocknote/shadcn** | 加 `@source` + `@theme`，修好斜杠菜单/格式工具栏 |

已替换：顶栏按钮/提示/账号菜单、文档动作按钮、命令面板、笔记右键菜单、AI 助手（ChatDock）。
