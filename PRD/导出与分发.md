---

## 0. 一句话

同一份 `SceneScript`，两条渲染通道：**实时**（PixiJS+VRM，可交互）与**离线**（Revideo，出视频）。
文档正文则从 BlockNote 导出。两者是"落盘形态"的最终产物。

---

## 1. 导出

用户可见的导出**只有两种**（其余为内部用）：

| 产物 | 技术 | 说明 |
|---|---|---|
| **动态视频** | Revideo 离线渲染 | 消费同一 `SceneScript` → MP4 / WebM |
| **文档正文** | BlockNote exporter（xl-exporter） | Markdown / PDF |

不做面向用户的 PNG / 场景 JSON 导出（内部调试可留）。

### 动态视频
- 输入：`SceneScript` + 知识快照（复用 `CanvasSnapshot`）。
- 渲染：Revideo，**不参与实时**（ADR：避免掉帧）。
- 线程：放 worker / 主进程，进度条 + 可取消。
- 桌面端：在 Electron main 跑（见 `PRD/桌面端.md`），Web 端走服务端任务。

### 文档正文
- 以文档块为唯一来源（`PRD/知识模型.md` §5 不变量 5）。
- 图片/画布帧可内嵌（导出时按节点截图）。

---

## 2. 保存（版本快照）

- 自动存始终开启（IndexedDB / Yjs）。
- 「保存」按钮 = 手动打一个**命名版本快照**（可用于回滚）。
- 脏标记：有未快照改动时显示「● 未保存」。

## 3. 分享

- 生成**只读链接**（不含编辑态）。
- 可设有效期 / 密码（后置）。
- AGPL 要求：网络服务需向用户提供源码入口（见 LICENSE）。

## 4. 搜索（Orama）

- 索引：笔记标题 / 正文 / 节点 title+summary+roles / 标签。
- 客户端索引（Orama），跨笔记。**不用 Meilisearch**（BUSL 与 AGPL 许可不相容）。
- 入口：`⌘K` 命令面板；结果按类型分组；动作 = 跳笔记 / 画布聚焦节点 / 就地建节点。

---

## 5. 与桌面端的关系

桌面端（Electron）把导出放主进程：可直接写本地文件、跑 Revideo worker、
无需上传到服务器。Web 端导出则走后端任务队列。
